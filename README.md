# boat-oriten：オリジナル展示データを集める

ボートレース各場の公式サイトが出している「オリジナル展示データ」（一周・まわり足・直線のタイム）を、1ページずつ間を空けて読み、表（CSV）にして貯める。

- 江戸川・津はオリジナル展示を出していない。ほかの22場は各場の公式サイトに載っている。
- 今読めるのは `oriten/venues.py` の `VENUES` の15場（桐生・戸田・多摩川・浜名湖・常滑・三国・びわこ・尼崎・鳴門・徳山・下関・若松・芦屋・福岡・唐津）。戸田は表ではなく XML（race_table_original_RR.xml）。平和島・蒲郡・住之江・丸亀・児島・宮島・大村はページの場所がまだ分からない。
- 桐生は一周ではなく半周（`lap_kind` 列に「半周」）。徳山・尼崎は直線が無い。まわり足の測る区間は場ごとに違うので、比べるのは同じ場・同じレースの中で。

## 動かし方（GitHub の Actions タブ）

| 名前 | いつ | 何をする |
| --- | --- | --- |
| probe | 手で | 分かっている場が何年前までさかのぼれるか、まだ分からない場のページの場所を調べて `probe/` に置く |
| backfill | 手で | 場（カンマ区切り）と期間を指定して、さかのぼって集める。場×期間ごとに分けて同時に動かし、最後に `data/` にまとめる |
| daily | 毎日 日本時間0:30 | 前の日の分を集めて `data/` に足す |

## できるファイル

`data/場番号/年.csv`：date, venue, race, lane（枠）, reg（登録番号）, ex（展示タイム）, lap（一周または半周）, lap_kind, turn（まわり足）, straight（直線）。計測できなかったところは空。

`data/summary.csv`：場・月ごとの行数。

## 読み方の決まり

- 同じサイトには1.5秒以上あけて読む。エラーのときは待ってからやり直す。
- 各場のサイトの robots.txt で止められていないページだけを読む。
