# q12：2連複1=2 の戻りモデル（オッズを使わない）

「その目を100円買ったら戻りはいくらか」を、出走表と直前情報（展示）だけから当てる木のモデル3本で、2連複1=2 を買うレースを選ぶ。

- `model_2026A.json`：2017年1月〜2024年12月のレースで作り、2025年の見込みの分位点を線にした3本（乱数0・1・2、HistGradientBoosting・ポアソン）。2026年の間はこれを使い、2027年1月に「2025年まで・線は2026年」で作り直す。
- `q12core.js`：BoatraceOpenAPI v1 の1レースから学習と同じ143項目を作り、3本の見込みと印を出す（Python と小数点以下10桁まで一致を確かめた）。
- 印：★★＝3本の「見込み÷上位2%の線」の平均が1以上。★＝「上位5%の線」で1以上（★★を除く）。1号艇か2号艇が展示に出ていない（欠場）レースは買わない。
- `record.js`：毎日（日本時間7:20、Actions の q12-record）前の日までの全レースの見込み・印・結果を、`models.json` に並べた目ごとに足し、`summary.md` を作り直す。2連複1=2 は `record_年.csv`。
- 記録だけ（お金は張らない）：2連複1=3（`model_2026A_q13.json`・`record_q13_年.csv`）、2連単1-2（`model_2026A_e12.json`・`record_e12_年.csv`）、2連単1-3（`model_2026A_e13.json`・`record_e13_年.csv`）。同じ作り方の確かめで ★以上 100%・97%・96%、★★ 105%・103%・102% と、1=2 ほどの利がなかったので、数字だけ追う。
