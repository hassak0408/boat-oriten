# q12：2連複1=2 の戻りモデル（オッズを使わない）

「その目を100円買ったら戻りはいくらか」を、出走表と直前情報（展示）だけから当てる木のモデル3本で、2連複1=2 を買うレースを選ぶ。

- `model_2026A.json`：いまの戻りモデル。2017年1月〜2024年12月のレースで作り、2025年の見込みの分位点を線にした3本（乱数0・1・2、HistGradientBoosting・ポアソン）。2026年の間はこれを使い、2027年1月に「2025年まで・線は2026年」で作り直す。
- `model_2026A_c10.json`・`model_2026A_c6.json`：頭打ちの戻りモデル。学習の答えを配当10倍・6倍で頭打ちにして作った3本（ほかは同じ）。大きな配当1本に引っぱられず、よく来るレースを選ぶ。
- `model_2026A_hit.json`：的中見込み（「2連複1=2が来る確率」を当てる木のモデル3本、2017年1月〜2024年12月で作成）。
- `q12core.js`：BoatraceOpenAPI v1 の1レースから学習と同じ143項目を作り、3本の見込みと印、的中見込みを出す（Python と小数点以下10桁まで一致を確かめた）。
- 印：★★＝3本の「見込み÷上位2%の線」の平均が1以上。★＝「上位5%の線」で1以上（★★を除く）。1号艇か2号艇が展示に出ていない（欠場）レースは買わない。
- 通知の選び方（boat_q12_alert.gs の RULE、★★だけ）：BAC＝B＋A★★＋C★★（2026-10-23からの既定。締切10:00〜20:50で1日4.1R・的中約30%・回収約107%）、B＝頭打ち10倍＋的中見込み25%以上（1.4R・約35%・約108%）、BA・BC、A＝いまの戻りモデル、C＝頭打ち6倍。
- `model_2026_cand.json`：朝の「今日の候補レース」。展示の前（出走表だけの94項目）で、そのレースが通知（B・A★★・C★★のどれか）になる見込みを当てる確率のモデル3本（2022年1月〜2026年9月の毎年作り直しの印で作成）。2025〜2026年の確かめで、1日の上位15レースに通知の約73%が入った。通知は毎朝9:00すぎに上位15レースを締切の早い順に送る。
- オッズの目安（EV_MIN）：通知の既定は 0（オッズを見ずに★★を全部買う、2026-10-22から）。確定オッズでは「的中見込み×2連複1=2のオッズが0.8未満を見送る」と B 113.5%（483点）→118.8%（414点）だったが、締切前のオッズ（2026-10-10〜12 の記録、的中見込み25%以上の192レース）で決めると、買いになった124点が回収59%・見送りになった68点が98%と逆になった（確定オッズで決めると113点85%・79点55%）。締切前にオッズが安かったレースほどよく来ていた。3日分だけなので、下の `snap.js` で記録をためて決め直す。
- `snap.js`：締切前のオッズの記録（Actions の q12-snap、毎朝8:05に動き出して1日3回ほど自分でつなぐ）。その日の全レースを締切の約12分前（通知のころ）・5分前（黒石で買うころ）・2分前に1回ずつ公式サイトの2連単・2連複のページから読み、`snap/日付.csv` に残す（読み始めは1秒に1回まで）。
- `odds_hist.js`：過去のレースの確定オッズを公式サイトから読んで `odds_hist.csv` に足す（Actions の q12-odds、手で1回動かすと読み終わるまで自分でつなぐ。`odds_targets.csv` の順＝通知Bのレース→★だけ・的中見込み25%以上→ほかの★★）。
- `record.js`：毎日（日本時間7:20、Actions の q12-record）前の日までの全レースの見込み・印・結果・的中見込みを、`models.json` に並べたモデルごとに足し、`summary.md` を作り直す。いまの1=2は `record_年.csv`、頭打ち10倍は `record_c10_年.csv`、頭打ち6倍は `record_c6_年.csv`（的中見込みの列のあとに確定オッズの列。確定オッズは turnmark のデータが出た日から埋め、summary.md に確定オッズで見た見送りの行を参考として出す。通知では見送らない）。
- 記録だけ（お金は張らない）：2連複1=3（`model_2026A_q13.json`・`record_q13_年.csv`）、2連単1-2（`model_2026A_e12.json`・`record_e12_年.csv`）、2連単1-3（`model_2026A_e13.json`・`record_e13_年.csv`）。同じ作り方の確かめで ★以上 100%・97%・96%、★★ 105%・103%・102% と、1=2 ほどの利がなかったので、数字だけ追う。
